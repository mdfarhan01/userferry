
# UserFerry – Export & Import Users

**A powerful WordPress plugin to export and import users with custom profile fields.**

Developed by [Md. Farhan Sadik](https://profiles.wordpress.org/farhansadik01/).

## Key Features

- Export users to CSV, XLSX, JSON, and XML.
- Import users from supported file formats.
- Automatically detect supported custom profile fields.
- Create, update, or skip existing users.
- Save and reuse export templates.
- Track import and export history.
- Process large datasets in batches.
