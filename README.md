## ✨ Overview

**UserFerry** is a WordPress plugin designed to make user data export and import easier. Export user accounts, select specific profile fields, import records from supported file formats, and manage reusable export templates.

Whether you're migrating users between WordPress websites or managing large user databases, UserFerry provides flexible tools to simplify the process.

## 🛠️ Custom Fields & Integrations

UserFerry can detect supported custom user metadata, including fields associated with:

- Advanced Custom Fields (ACF)
- Ultimate Member
- WooCommerce billing and shipping
- BuddyPress
- Meta Box
- JetEngine
- Registration form plugins
- Custom user metadata

Field availability depends on the data stored on your website and the supported metadata integrations.

---

## 🔐 Security & Data Handling

UserFerry includes safeguards designed to support responsible user data management:

- Permission-aware user role assignment.
- Protected export file storage.
- Configurable automatic cleanup of old files.
- File-size and data limits for imports.
- Row-level error reporting for failed imports.
- No third-party requests by default, except optional YouTube video playback after user interaction.

**Important:** Always keep a backup of your website before performing bulk user imports or updates.

## 📦 Installation

1. Download UserFerry from the [WordPress.org Plugin Directory](https://wordpress.org/plugins/userferry/).
2. Log in to your WordPress admin dashboard.
3. Navigate to **Plugins → Add New Plugin**.
4. Search for **UserFerry – Export & Import Users**.
5. Click **Install Now**, then **Activate**.
6. Open the **UserFerry** menu in your WordPress admin dashboard.

You can also download the ZIP file directly:

[**Download UserFerry ZIP**](https://downloads.wordpress.org/plugin/userferry.1.0.0.zip)
